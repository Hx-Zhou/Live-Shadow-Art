# API And Event Protocol

Generation API contract is defined in `packages/schemas/openapi.yaml`.

Gesture contract is defined in `web/src/gesture/GestureSource.ts` and mirrored in `packages/schemas/gesture-event.schema.json` plus `packages/schemas/continuous-signal.schema.json`.

Asset packs must contain:

- `preview.png`
- fixed part PNG files
- `rig.json`
- `manifest.json`
