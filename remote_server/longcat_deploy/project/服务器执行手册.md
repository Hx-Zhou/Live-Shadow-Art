# 租用服务器执行手册

## 0. 上传准备包

把整个 `成员A_昇腾LongCat部署准备包` 目录上传到服务器。不要只复制单个脚本，因为提示词、负向提示和基准程序使用相对路径。

## 1. 只读预检

```bash
cd 成员A_昇腾LongCat部署准备包
bash scripts/00_preflight.sh
```

先阅读生成的 `preflight_*.log`。驱动不可用、NPU健康状态异常或磁盘不足时停止，避免开始计费型下载。

## 2. 启动匹配卡型的容器

先查看成本，不执行：

```bash
bash scripts/01_start_container.sh
```

A2/910B示例：

```bash
ASCEND_VARIANT=A2 NPU_COUNT=2 MODEL_CACHE=/data/models \
  bash scripts/01_start_container.sh --execute
```

A3示例：

```bash
ASCEND_VARIANT=A3 NPU_COUNT=2 MODEL_CACHE=/data/models \
  bash scripts/01_start_container.sh --execute
```

容器中项目目录固定为 `/workspace/project`，模型目录固定为 `/data/models`。

## 3. 安装 vLLM-Omni 源码

在容器内部运行：

```bash
cd /workspace/project
bash scripts/02_install_vllm_omni.sh
bash scripts/02_install_vllm_omni.sh --execute
```

脚本会检查 vLLM 版本、克隆 `v0.23.0rc1`、editable安装并执行 `pip check`。如果依赖解析要升级 vLLM、torch或torch_npu，立即停止，不要接受自动跨版本升级。

## 4. 下载并固定模型 revision

```bash
cd /workspace/project
bash scripts/03_download_longcat.sh
MODEL_DIR=/data/models/LongCat-Image \
  bash scripts/03_download_longcat.sh --execute
```

下载脚本先解析 Hugging Face 当前提交 SHA，再以该 SHA 下载，并写入 `/data/models/LongCat-Image/MODEL_REVISION.txt`。将这个 SHA 写回答辩材料和版本记录。

## 5. 冒烟测试

两张卡先尝试 Ulysses：

```bash
cd /workspace/project
ULYSSES_DEGREE=2 TENSOR_PARALLEL_SIZE=1 CFG_PARALLEL_SIZE=1 \
  bash scripts/04_smoke_longcat.sh
```

冒烟默认是 768×768、10步，只验证“文本编码器→DiT→scheduler→VAE→PNG”完整链路，不评价最终画质。

如果失败：

1. 先查看 `outputs/smoke/longcat_smoke.log`；
2. 排除 dtype、device、动态shape和attention mask；
3. Ulysses失败时改为 `ULYSSES_DEGREE=1 TENSOR_PARALLEL_SIZE=2`；
4. 不要同时改变版本、并行方式和模型代码。

## 6. 正式基准

```bash
cd /workspace/project
ULYSSES_DEGREE=2 BENCHMARK_STEPS=50 GUIDANCE_SCALE=4.0 \
  bash scripts/05_run_benchmark.sh
```

输出：

- `outputs/benchmark/images/`：30张图片；
- `outputs/benchmark/logs/`：每张独立日志；
- `outputs/benchmark/performance.csv`：返回码和墙钟延迟。

中断后继续：目前包装脚本未默认传 `--resume`。可以直接运行：

```bash
python3 tools/benchmark.py --help
```

并在完整命令末尾添加 `--resume`，已有成功图片将跳过。

## 7. 适配工作顺序

1. 保存未修改基线、固定模型revision和30张结果。
2. 用 profiler 找端到端耗时前三项。
3. 优先接现有 `torch_npu`/MindIE-SD融合算子。
4. 只有 shape 不兼容且热点占比足够高时，自写一个小型 Ascend C 算子。
5. 用相同 prompts、seeds、分辨率和步数复测。
6. 汇总速度、峰值HBM、任务成功率和图像差异。

## 8. 回传本地的文件

- `preflight_*.log`
- `MODEL_REVISION.txt`
- `outputs/benchmark/performance.csv`
- 30张基线图与30张优化图
- profiler报告
- 修改过的代码补丁或Git commit
- 填写后的 `templates/评分表.csv`
