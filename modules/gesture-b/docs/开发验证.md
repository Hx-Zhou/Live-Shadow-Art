浏览器冒烟测试曾捕获并修复：根地址相对资源路径错误；MediaPipe WASM 的 importScripts 不支持 module Worker。当前使用 classic Worker 内动态 import JS 运行库。

模拟摄像头没有真实手，推理可能走较轻的无手路径；headless 渲染帧率也不代表真实显示。因此不将开发测试中显示的 FPS/P95 写成验收指标。
