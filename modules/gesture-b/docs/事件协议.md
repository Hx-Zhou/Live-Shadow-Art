# 手势接口 1.0（待成员 C 联调确认）

依据计划书 7.8 保留 `type/action/confidence/hand/position/direction/timestamp` 字段，新增 `version` 和信号类型。计划书中的示例没有时间单位，本工程明确为 **performance.now() 毫秒单调时钟**；不是 Unix 时间。跨页面或存储回放必须由接收端建立时钟映射。

## 连续控制

```json
{"version":"1.0","type":"gesture_control","hand":"right","position":{"x":0.6,"y":0.4},"direction":{"x":1,"y":0},"bodyAngle":-1.2,"armAngle":0,"pinchStrength":0.2,"active":true,"label":"point","confidence":0.85,"timestamp":1234.5}
```

- position：镜像屏幕空间，左上 (0,0)、右下 (1,1)，校准后限幅。摄像头输入不镜像，只镜像预览及输出 x。
- direction：食指 MCP→TIP 在镜像屏幕空间的二维单位向量；退化向量输出 (0,0)。
- bodyAngle、armAngle：弧度，屏幕 x 轴向右，y 向下；armAngle 限幅 [-2.6,2.6]。具体肩肘运动限制属于成员 C 骨架配置。
- pinchStrength：[0,1]；active=false 时接收端应保持当前角色位置并暂停动作。
- hand：MediaPipe 返回的左右手类别小写，按未镜像输入传入；正式设备必须用左右手实测确认。该字段不是参与者身份。
- label：open_palm / fist / point / pinch / victory / None。

## 离散动作

```json
{"version":"1.0","type":"gesture_action","action":"pinch","confidence":0.85,"confidenceKind":"rule_score","hand":"right","position":{"x":0.6,"y":0.4},"direction":{"x":1,"y":0},"timestamp":1234.5}
```

| action | 建议动作 | 本模块抑制机制 |
|---|---|---|
| activate | 激活控制 | 连续 5 帧张掌 |
| pause | 暂停 | 握拳候选持续至少 300 ms + 投票 |
| point | 指向/选择 | 最近 5 帧至少 4 帧一致 |
| pinch | 攻击/拾取 | 进入 0.28、退出 0.42 掌宽距离比（规则模式）；投票和边沿 |
| victory | 预留选择事件 | 第 5 个静态类建议，待团队确认 |
| swipe | 转身 | 250 ms 轨迹窗口，水平位移 >0.18、速度 >0.85/s、主方向比 >1.8 |
| raise | 跳跃 | 250 ms 窗口，上移 >0.16、速度 >0.75/s、主方向比 >1.8 |

动作统一 500 ms 冷却，持续静态姿势不重复触发；需先释放再重新做动作。MLP 模式用类别概率及 0.75 阈值，不采用规则分类器的捏合距离滞回；时序投票、冷却仍生效。不要将规则的 0.85 分数解释为统计置信概率。非激活状态仅允许 activate/pause。

动态动作 `confidenceKind=trajectory_rule_score`，分数 0.85 代表规则通过，与静态手型概率独立。机器可读字段约束位于 `schemas/gesture-event.schema.json`。

## 跟踪状态

```json
{"version":"1.0","type":"gesture_status","status":"lost","timestamp":1234.5}
```

status 为 tracking/lost。短于 125 ms 丢手不发新控制值，接收端保持姿态；超时发一次 lost，清空轨迹、投票并暂停。重新识别必须再次张掌激活。丢帧结果超过 250 ms 会被丢弃；推理线程超过 5 秒无结果会关闭并报错。

## 责任边界

成员 B 输出输入意图；成员 C 决定受击期间能否攻击、拾取范围、跳跃落地、骨架层级和关节约束。不要以手势事件跳过舞台状态机。正式联调需确认：V 手势用途、左右手方向、角色坐标、动作冷却及目标端到端延迟。

多人防干扰采用左右手类别和手腕空间连续性，并非身份识别；两个相同类别的手重叠穿越可能误接管。现场优先单人单手、清空背景中的手，真机鲁棒性测试必须记录该局限。
