# Generation Models

Model weights are intentionally excluded from Git.

Expected layout:

- `sd15/`: base Stable Diffusion weights or download notes.
- `lora/`: shadow-puppet style LoRA weights and license notes.
- `converted/`: Ascend-converted model files.
- `configs/`: model versions, inference settings and checksums.

Record every usable model in `configs/model-versions.json`.
